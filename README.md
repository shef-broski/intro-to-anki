# intro-to-anki

Free guide introducing digital flashcards, active recall, and spaced repetition for language learners.

## About
This document provides a beginner-friendly overview of how Anki works and why it can be effective for long-term vocabulary retention. It is designed to be accessible to language learners and non-technical readers.
